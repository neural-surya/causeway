# Causeway

A team of agents that investigates failing releases and incidents in a synthetic company, and backs every conclusion with a verifiable path through a FalkorDB graph.

Built for [Graph Hacks](https://www.wemakedevs.org/hackathons/falkordb) by WeMakeDevs and FalkorDB.
Tracks: Agents That Act on Connected Data, Agent Memory and Coordination, Company Brain.

Work in progress. `make test` runs the suite (starts FalkorDB via Docker).
